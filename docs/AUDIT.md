## 合并结果

| 最终应用 | 合并内容 | 原因 |
| --- | --- | --- |
| 豆瓣 | 广告规则 + `feature_switch` 开屏 SDK 补丁 | 同一客户端，补丁用于解决接口被拦截后仍展示 SDK 开屏的问题 |
| 菜鸟 | 广告规则 + 每日现金任务规则 | 同一客户端且接口不重叠，合并后可只装一个插件 |
| 微信 | 小程序规则 + 微信公众号规则 | 同一客户端，将最终显示名统一为“微信” |
| 哔哩哔哩 | 使用完整开关版，归档保守版和极简版 | 完整版已包含保守行为，并可用开关控制高风险处理 |

京东和京东外卖对应不同客户端，不合并。

## 开关审计

只增加高风险、实验性或划分明确的功能开关，没有为每条普通请求拦截机械添加按钮。

| 应用 | 开关 | 默认 | 原因 |
| --- | --- | --- | --- |
| 12306 | 应用内推广过滤 | 开 | 请求头条件会命中多个应用内接口，关闭后可只保留开屏过滤 |
| 菜鸟 | 每日现金任务 | 开 | 会清空整个任务接口 `data`，页面异常时可单独关闭 |
| 闲鱼 | 场景恢复候选拦截 | 关 | 原规则未经过真机验证，且会作用于该接口所有场景 |
| 麦当劳 | 开屏投放过期处理、推广弹窗过滤 | 开 | 属于两个独立功能，便于定位开屏兼容问题 |
| 哔哩哔哩 | 完整独立开关 | 广告处理开，弹幕/播放/评论等高风险项关 | 避免为了普通去广告改写弹幕、播放进度和播放能力 |
| 网易云音乐 | 首页、底栏、评论、发现页、个人页等 | 沿用原设置 | 页面精简与纯广告过滤边界明显 |
| 微博 | 开屏、信息流、评论、搜索、个人页、视频等 | 开启 | 功能作用于不同页面，便于单独排障 |
| 小红书 | 开屏、信息流、弹窗、搜索、保存等 | 开启 | 保存图片/视频属于非去广告功能，需要可关闭 |
| 百度贴吧 | 推荐页视频帖过滤 | 开 | 会移除正常视频内容，不属于纯广告 |

## 当前验证边界

- 已完成：文件存在性、显示名、元数据、MitM 主机、规则重复、局域网脚本残留、脚本文件存在性。
- 尚未完成：iPhone 上逐应用导入、证书信任、DNS、HTTP/2、QUIC、页面布局和正常功能回归。
- 已知外部依赖：高德地图的两个 `jq_file`。哔哩哔哩的上游 JS 与 jq 已迁入本仓库。
