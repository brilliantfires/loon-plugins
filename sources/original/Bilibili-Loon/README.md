# Bilibili Loon 本地整理

这个目录保存了截图中的哔哩哔哩 Loon 插件来源、作者当前版本，以及三个本地整理的变体。直接使用推荐：

**[Bilibili-Ads-Full.lpx](./Bilibili-Ads-Full.lpx)**

完整版默认与保守版一致：只打开开屏、推荐流、搜索、直播和明确广告素材，其他扩展全部关闭。想减少误伤时直接保持默认即可；需要某项增强时，再单独打开对应开关。

## 三个本地版本

| 文件 | 用途 | 默认行为 |
| --- | --- | --- |
| `Bilibili-Ads-Full.lpx` | 推荐管理使用；包含全部可安全开关化的增强功能 | 与保守版行为一致 |
| `Bilibili-Ads-Conservative.lpx` | 固定核心去广告功能，配置项更少 | 不处理弹幕、播放进度、播放地址、青少年模式 |
| `Bilibili-Ads-Minimal.lpx` | 完全不加载 JavaScript，只使用 JSON/JQ 改写 | 不处理任何 protobuf 接口 |

### 完整版默认开启

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 开屏与启动广告 | 开 | 清理启动素材和 `splash` 接口 |
| 推荐流显式广告 | 开 | 只删除带 `ad_info` 的卡片及明确的竖屏广告类型 |
| 搜索结果显式广告 | 开 | 只过滤 `linktype` 中带 `_ad_` 的结果 |
| 直播广告与购物浮层 | 开 | 清理直播 banner、活动卡、购物信息等明确推广位 |
| 明确广告素材接口 | 开 | 处理 VIP 广告素材与 PGC 投放素材接口 |

### 完整版默认关闭

| 开关 | 影响范围 |
| --- | --- |
| 首页只保留视频卡片、推荐流卡片附加广告字段 | 推荐流非视频卡片和故事卡附加信息 |
| 搜索热词精简 | `DefaultWords` 与搜索广场 |
| 评论处理总开关、过滤评论推广文字 | 评论置顶卡片与推广关键词；后者必须在总开关开启后使用 |
| 动态页处理总开关、最常访问显示方式 | 动态广告、直播推荐、话题卡及最常访问分组 |
| 视频页扩展广告 | 视频页元数据、付费栏与相关推荐 |
| 页面与标签精简、账号页整理 | 顶部资源、皮肤、底部标签和“我的”页面入口 |
| 播放结束页与暂停页素材、会员状态本地显示 | 播放周边素材和客户端会员外观 |
| 请求重取优化 | 视频页与评论请求重试 |
| 互动弹幕命令清理 | 只处理 `DmView` 中的投票、购物等互动弹幕命令 |
| 空降助手 | 读取第三方分段，改写 `DmSegMobile` 与 `ViewProgress` |
| 播放能力增强 | 改写 `PlayView` / `PlayViewUnite`，影响后台播放和投屏 |
| 关闭青少年提示、P2P 节点改写 | 青少年模式响应与 tracker 配置 |
| 旧域名请求拦截、网页活动页清理 | 四个旧 `biliapi` 主机的 HTTPS 请求及网页活动页 |

所有扩展都默认关闭。普通横屏弹幕、评论列表、视频播放进度和播放地址响应在默认配置下不改写。上游中的全局 DNS 拒绝、聊天 P2P 域名规则和固定端口拒绝无法由 Loon 的单个插件开关独立控制，因此没有伪装成开关放入完整版；需要这类更激进行为时应单独建立网络规则。

## 导入 Loon

当前 Mac 的局域网地址为 `192.168.3.35`，本地服务端口为 `18766`。手机与 Mac 在同一 Wi-Fi、服务保持运行时，可以直接打开：

[在 Loon 中导入完整开关版](loon://import?plugin=http%3A%2F%2F192.168.3.35%3A18766%2FBilibili-Ads-Full.lpx)

如果 Mac 的 IP 变化，双击 `serve-local.command`，按它打印的新地址替换上面链接中的 IP。也可以把 `.lpx` 隔空投送到 iPhone，选择用 Loon 打开。

导入后：

1. 确认 Loon 已开启 HTTPS 解密 / MitM，并按提示信任证书。
2. 打开插件设置；除五个核心开关外，其余先保持关闭。
3. 强制结束哔哩哔哩后重新打开，分别检查视频、直播、搜索和评论区。
4. 一次只打开一个扩展开关并重新打开 App，出了问题能快速定位是哪一个规则。

## 开销与广告范围

默认只对实际匹配的广告响应执行 JSON/JQ 改写，没有常驻轮询。完整版增加的已关闭规则会增加少量配置匹配，Loon 还可能为旧域名和网页活动页建立解密范围，但不会执行对应脚本；因此默认网络请求开销接近保守版。

打开 `空降助手` 后会额外请求 `bsbsb.top`；打开 protobuf 扩展后，脚本会先解压、解析、修改再重新编码对应响应。弹幕、评论和视频请求本身越大，开销越明显。日志等级保持 `off`，排查时再临时改为 `error` 或 `warn`。

核心开关清理的是开屏、推荐流 `ad_info`、搜索 `_ad_` 结果、直播 banner/活动卡/购物浮层、VIP/PGC 投放素材。扩展开关涉及的“相关推荐”“最常访问”“页面入口”属于功能精简，不全是广告，所以默认关闭。

## 管理与回滚

- 日常使用：保留 `Bilibili-Ads-Full.lpx`，扩展开关保持关闭。
- 插件报错或页面显示异常：先关闭推荐流/直播开关；仍异常则切换到 `Bilibili-Ads-Minimal.lpx`。
- 想完全恢复官方行为：在 Loon 中停用本插件，并删除对应 MitM 主机名；本目录不会修改 Loon 的其他配置。
- 本地静态检查：运行 `./verify.sh`；需要联网核对固定脚本时运行 `./verify-remote.sh`。

已验证的范围包括文件完整性、脚本 JavaScript 语法、完整版危险接口的独立开关保护、保守版危险接口隔离、固定脚本 URL 可达性及哈希一致性。还没有在你的 iPhone、当前 Bilibili App 版本和登录账号上做真机验收。
